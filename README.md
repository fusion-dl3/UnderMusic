# UnderMusic

Aplicación móvil para el descubrimiento y conexión de artistas musicales emergentes basada en ubicación geográfica e interacción social.

## Proyecto

UnderMusic es un proyecto desarrollado como parte de un proyecto de tesis de Ingeniería en Computación e Informática.

La aplicación busca facilitar el descubrimiento de artistas musicales emergentes mediante filtros geográficos y de género musical, permitiendo además distintas formas de interacción entre artistas y oyentes.

## Tecnologías principales

### Frontend
- React Native

### Backend

### Base de datos
- MongoDB
